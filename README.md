# Logistics Delivery Performance Analysis and Delivery Time Prediction

## Project Overview

This project is being developed as part of a Logistics Data Analyst Internship. It focuses on analyzing food delivery performance, understanding factors associated with delivery duration, and exploring the use of machine learning to predict delivery time.

The project uses Python-based data analytics techniques to inspect data quality, calculate performance indicators, visualize patterns, and evaluate a suitable prediction model.

## Objectives

- Analyze delivery duration and its distribution.
- Examine the relationship between delivery time and distance.
- Compare delivery performance across traffic levels, weather conditions, vehicle types, and order types.
- Identify and document missing values and data quality issues.
- Develop visualizations that support data-driven interpretation.
- Explore regression models for delivery-time prediction.
- Propose practical recommendations based on validated findings.

## Dataset

**Dataset:** Food Delivery Dataset from India for Delivery Time Prediction

**Source:** [Zenodo dataset record](https://zenodo.org/records/18370027)

The working Excel file contains 10,001 rows and 17 columns, including delivery-person attributes, location coordinates, order type, vehicle type, weather conditions, traffic level, distance, and delivery time.

The dataset requires further validation and preprocessing before final analysis. Its usage terms should be checked before redistributing the file or publishing it in this repository.
